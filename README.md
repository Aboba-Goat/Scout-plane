# Scout-plane
Planes are cool, watching a plane fly makes you reminisce on how far technology has brought human kind. But do you know what is even cooler? Watching a plane that's watching you! (and everything else around) from 20-30 m up in the air.
That's why me and a friend created a practical cheap stable efficient and modular RC plane never before seen (That can record).
